# Public frontend source

This directory contains the curated public frontend snapshot used for architecture and implementation reference.

Production-only visual assets are intentionally absent, including avatar, favicon, Sakana resources, wind-chime asset and dedication image. The HTML/CSS/JS may retain references to those resources because this repository mirrors the public frontend structure rather than acting as a standalone deployment bundle.

No production backend, authentication configuration, message database, reverse-proxy configuration, certificates or secrets are included.
